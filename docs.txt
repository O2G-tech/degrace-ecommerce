MILESTONE 5 — Authentication

Customers should be able to:

Register
   ↓
Login
   ↓
Account
   ↓
Logout

Registration:

Name
Email
Phone
Password
Confirm Password

Login:

Email
Password

We'll also have:

Forgot Password
Reset Password
User Profile

Passwords must be stored using PHP's:

password_hash()

and checked using:

password_verify()
MILESTONE 6 — Dynamic Products

This is where your store starts becoming a real e-commerce application.

Products will come from MySQL rather than being hard-coded in React.

Customer can:

Browse products
Search products
Filter products
Sort products
View product
Select category
Select subcategory

For example:

Home
 ↓
Kitchen
 ↓
Blenders
 ↓
Products

And:

Phones
 ↓
Products

This follows the category structure we just established.

Customer can:

Add to Cart
     ↓
Cart
     ↓
Increase quantity
Decrease quantity
Remove product
     ↓
Calculate subtotal
     ↓
Calculate total

Example:

Silver Crest Blender     ₦35,000 × 2
Electric Kettle          ₦18,500 × 1
-------------------------------------
Subtotal                 ₦88,500
Delivery                 ₦5,000
-------------------------------------
Total                    ₦93,500

The cart should be associated with the logged-in customer.

MILESTONE 11 — Payment

For a Nigerian e-commerce website, we can integrate a payment provider such as:

Paystack
Flutterwave

The flow becomes:

Customer
   ↓
Checkout
   ↓
Create Order
   ↓
Payment Gateway
   ↓
Payment
   ↓
Payment Verification
   ↓
Order Confirmed

We should not simply mark an order as paid because the frontend says payment succeeded. The PHP backend should verify the transaction with the payment provider.
